PORTFOLIO LINUS KINTI — NOTES DE DÉPLOIEMENT

1) Dépôt prévu : https://linuskinti-ship-it.github.io/mon-portfolio/
   Si le nom réel du dépôt GitHub est différent, remplacez l'URL ci-dessus dans :
   - index.html (og:image et twitter:image)
   - robots.txt (directive Sitemap)
   - sitemap.xml (toutes les balises loc)

2) GitHub Pages : Settings > Pages > Deploy from a branch > main > /(root) > Save.
   Après publication, activer « Enforce HTTPS » dans Settings > Pages lorsque l'option est disponible.

3) Aucun secret ni clé API n'est présent dans les fichiers. Ne jamais placer de clé privée,
   mot de passe ou jeton d'accès dans HTML, CSS ou JavaScript public.

4) Aucun outil d'audience n'est installé. Pour en ajouter un, choisir un fournisseur respectueux
   de la vie privée, configurer son identifiant public de site, puis mettre à jour la politique
   de confidentialité et le mécanisme de consentement avant activation. Ne pas mettre de clé secrète
   dans le navigateur.

5) Le portfolio ne possède pas de formulaire : validation de formulaire et anti-spam ne s'appliquent
   pas actuellement. Les contacts se font par e-mail, téléphone ou LinkedIn. Si un formulaire est
   ajouté, il faudra un service/backend adapté pour la validation côté serveur et l'anti-spam.

6) Les textes juridiques sont des modèles informatifs, pas un avis juridique. Les faire vérifier
   selon les règles applicables au Bénin avant usage professionnel/commercial.
